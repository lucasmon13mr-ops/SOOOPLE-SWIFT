Integração Rápida do SDK

          

            O endpoint de verificação POST /api/sdk/verify requer token,
            key, device_id e uma
            signature = Assinatura v3 HMAC sobre a requisição canônica incluindo o Instance ID.
          

          
POST /api/sdk/verify
{
  "token": "PACKAGE_TOKEN",
  "key": "LICENSE_KEY",
  "device_id": "ID da instância do Keychain",
  "signature": "hmac_hex_of_(key + '|' + device_id)",
  "device_name": "iPhone 15",
  "hwid": "hash de identificação de hardware",
  "os_info": "iOS 18",
  "dylibs": 2
}

          
Opcional: envie dylibs (contagem de dylibs carregadas, igual à verificação do próprio SDK). Se o pacote tiver a opção Desativar Injeção e a contagem exceder o Máximo de dylibs, a verificação é rejeitada como injection_detected.
